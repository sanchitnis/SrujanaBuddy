# CV-for-Role Plugin

This plugin provides a comprehensive resume tailoring assistant for applicants (students or experienced professionals).

## Features
- ATS-ready resume generation (Markdown)
- Cover letter with tone selection
- Interview Q&A (multi-round)
- Scoring dashboard (Match %, ATS %, Gap score)
- 2-minute video resume script

## Skills
- `generate-resume`
- `generate-cover-letter`
- `generate-interview-qa`
- `generate-scoring-dashboard`
- `generate-video-resume-script`

## Usage
- Integrate with agent workflows or use as standalone tools
- See `cv-for-role.md` for skill specifications and flows

## Compliance
- Consent-first, evidence-based, Indian legal compliance
- Inclusive for all experience levels

## How to Extend
- Add new skills or improve templates as per PRD
- See `docs/cv-for-role-prd.md` for requirements
