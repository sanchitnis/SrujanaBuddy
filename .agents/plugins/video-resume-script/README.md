# Video Resume Script Plugin

This plugin provides a skill to generate a 2-minute video resume script for any applicant (student or experienced professional) based on their experience, achievements, and target role.

## Features
- Prompts for applicant details (name, experience, achievements, target role, skills)
- Generates a concise, ready-to-record script (Markdown, ~2 minutes)
- Inclusive for all experience levels
- Provides recording tips

## Usage
- Use the Python script (`video-resume-script.py`) for CLI-based generation
- Use the Markdown skill spec (`video-resume-script.md`) for integration with agent workflows

## How to Run (Python CLI)

```sh
python video-resume-script.py
```

## Integration
- Register the skill in your agent system using the provided `plugin.json`
- Link from CV-for-Role workflows or use as a standalone tool

## Compliance
- All data is processed locally; no external API calls
- Inclusive language for all applicants
