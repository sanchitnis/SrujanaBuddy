# GTD Lite — Student Execution Skill

> Full operating policy and rules: [`gtd/GTD-GUIDE.md`](../../gtd/GTD-GUIDE.md)

## When to use

- Student is overwhelmed with tasks and needs to capture + clarify
- Weekly review is due or overdue
- Student wants to set up or reset their GTD system
- Session type 14 (Student GTD Rescue) or session type 3 (Weekly Svadhyaya Review)

## Quick procedures

### Inbox rescue (5 min)
1. Open `gtd/00-inbox.md`
2. For each item: Is it actionable?
   - **Yes** → does it take < 2 min? Do it now. Else → next actions or project.
   - **No** → reference, someday, or delete.
3. Inbox should be empty at end.

### Weekly review (15–20 min)
1. Empty inbox completely.
2. Review each project — update or add the one visible next action.
3. Reconcile calendar and waiting-for list.
4. Close stale items.
5. Set top 3 outcomes for next week.

### Student conventions
- Prefix academic tasks with `[ACA]`, career with `[CAR]`, wellbeing with `[WLB]`
- Include due dates only for real deadlines
- Add evidence links to completed milestones
- Keep next actions list below 15 items; keep projects below 8
