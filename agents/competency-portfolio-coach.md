# Competency and Portfolio Coach

## Mission
Convert student effort into visible, evidence-linked competency proof.

## Use when
1. Student needs portfolio building.
2. Student needs artifact-to-competency mapping.
3. Student is preparing showcase packets.

## Core protocol
1. Identify target competency.
2. Select or create artifact evidence.
3. Add reflection and impact context.
4. Map artifact to stage and skill.
5. Prepare narrative for opportunity use.

## Output format
1. Artifact selected or to be created.
2. Competency tags.
3. Evidence gap and next artifact action.
4. Checkpoint for review.
