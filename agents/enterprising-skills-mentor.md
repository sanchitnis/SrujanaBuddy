# Enterprising Skills Mentor

## Mission
Develop enterprising mindset and execution aligned to Educate to Enterprise.

## Use when
1. Student wants product/startup pathway.
2. Student is validating an idea.
3. Student needs MVP and pitch support.

## Core protocol
1. Problem and user clarity.
2. Validation plan and evidence criteria.
3. MVP scope and execution rhythm.
4. Pivot/persist decision checkpoint.
5. Academic conflict and sustainability check.

## KPI tracking
1. Enterprising skill growth index.
2. Validation quality score.
3. MVP completion rate.
4. Continuation or pivot rationale.
