# Connectors

Connectors define institutional and external handoff interfaces used by SrujanaBuddy.

## Active connectors
1. calendar-audit.md
2. manodhara-referral.md

## Connector contract
1. Trigger condition is explicit.
2. Required input fields are listed.
3. Output artifact format is defined.
4. Escalation owner is named.
5. SLA and follow-up window are stated.

## Usage notes
1. Treat connectors as operational specs, not coaching scripts.
2. Route only when trigger criteria are met.
3. Log connector usage in session evidence.
