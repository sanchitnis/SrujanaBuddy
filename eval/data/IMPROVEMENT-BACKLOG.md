# SrujanaBuddy Improvement Backlog

Live log of all improvement tasks raised from eval sessions, student feedback, mentor observations, and Board decisions.

**Managed by**: SrujanaBuddy Improvement Board (see [`eval/improvement-board.md`](../improvement-board.md))
**Format**: Each task follows the standard format defined in `improvement-board.md`.

---

## How to add a task

1. Copy the template block below.
2. Fill in all fields. Leave `Assigned to` and `Resolution` blank if not yet assigned.
3. Set `Status` to `open`.
4. Add the task at the **top** of the Active Tasks section (most recent first).
5. Increment the task number: IMP-YYYY-NNN where NNN is the next sequential number for that year.

---

## Task Template

```
---
Task ID:        IMP-YYYY-NNN
Raised by:      [Student / Mentor / Eval-Synthetic / Eval-Audit / Board]
Raised date:    YYYY-MM-DD
Stage affected: [1 / 2 / 3 / 4 / All]
Track affected: [Foundation / Application / Creation / Research / Venture / Career / All]
Agent affected: [filename or "SKILL.md" or "Framework" or "All"]
Failure type:   [F-1 through F-10, or "Philosophy", "Domain", "New Feature"]
Severity:       [S1-Critical / S2-High / S3-Medium / S4-Low]
Description:    [2–5 sentences]
Proposed fix:   [1–3 sentences, or "Unknown — board to determine"]
Assigned to:    [blank until assigned]
Status:         open
Resolution:     [blank until resolved]
---
```
