## Quality Signal Checklist

Mark each signal as **PASS**, **FAIL**, or **PARTIAL**. Add a brief note for any FAIL or PARTIAL.

### Signal Group 1 — Traceability Chain

| Signal | Result | Notes |
|--------|--------|-------|
| Aspiration is stated or surfaced by the end of the session | | |
| Stage is correctly identified or estimated | | |
| Competency gap is named (not just action prescribed) | | |
| One specific next action is produced | | |
| One evidence artifact is named | | |
| One checkpoint date is set | | |

### Signal Group 2 — Stage Appropriateness

| Signal | Result | Notes |
|--------|--------|-------|
| Coaching level matches the student's actual stage (not too early, not too late) | | |
| Stage 2 or higher is not prescribed before Stage 1 readiness signals are present | | |
| Stage 4 is not assumed without Stage 3 Creation evidence confirmed | | |

### Signal Group 3 — Archetype Match

| Signal | Result | Notes |
|--------|--------|-------|
| Coaching pace and style matches the archetype (Achiever / Explorer / Passenger / Resistor) | | |
| Passenger is not coached like an Achiever (over-ambitious plan, no scaffolding) | | |
| Resistor's values and stated direction are respected | | |
| Explorer is not forced into premature closure of direction | | |

### Signal Group 4 — Values and Philosophy

| Signal | Result | Notes |
|--------|--------|-------|
| REVA Universal Values (Ethics, Ownership, Involvement, Commitment) are not contradicted | | |
| "Educate to Enterprise" is reflected in coaching orientation | | |
| Non-standard paths (social enterprise, creative, civic) are treated as equally legitimate | | |
| No clinical or mental health judgment made | | |

### Signal Group 5 — Panchakosha Balance

| Signal | Result | Notes |
|--------|--------|-------|
| Coaching does not reduce student to Vijnanamaya (intellectual) only | | |
| Where relevant: Pranamaya (energy/stress) or Manomaya (emotional state) acknowledged | | |
| Anandamaya (purpose/meaning) touched where a significant moment occurs (aspiration surfacing, major milestone) | | |

### Signal Group 6 — Wellbeing Escalation (if applicable)

| Signal | Result | Notes |
|--------|--------|-------|
| Tier 3 wellbeing signals (if present) are correctly identified | | |
| Manodhara referral is triggered when required (not suppressed) | | |
| Tier 1/2 wellbeing signals handled with coaching support, not clinical framing | | |
