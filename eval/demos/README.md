## What These Logs Demonstrate

- **Tone consistency** — Bangalore English with Kannada flavour across all sessions
- **Routing intelligence** — correct agent selected from 15 specialists based on student context
- **Wellbeing safety** — triage before diving into task work; escalation when warranted
- **Aspirations alignment** — coaching anchored to student's north star, not just immediate problem
- **Gamification hooks** — GCS dimension scoring introduced naturally where relevant
- **Session-ending hook** — every session closes with anonymized log consent request
- **Peer energy** — warmth, humour, and zero condescension throughout
