---

## 🚀 Coach Quick Start

**To populate this leaderboard:**

1. **Every Friday evening** (after weekly coaching sessions), open each student's profile in `profiles/{full-name}.md`
2. Go to section `## GCS Gamification Analytics`
3. Extract data:
   - Interview count, sources, Investigation depth level
   - Number of documented pivots + logic clarity
   - Collaboration moves (conflict resolved, feedback given)
   - Prototype demo status, core logic, user testing
   - Reflection text
   - Sprint weeks completed, sessions on-time, consistency %
4. Update the relevant leaderboard tab below with latest data
5. Identify any new badge unlocks or Bold Bets achieved; add stories
6. Commit and push to repo
7. Notify students of new badges (if consented): *"🔄 Pivot Master badge unlocked for [Name]!"*

**Time**: ~30 mins for a cohort of 20 students.

## Privacy and Consent

- **Default**: Anonymous (Anon-001, Anon-002, etc.)
- **Opt-in**: Student can consent to show real name; update profile `Public Leaderboard Consent → Appear on leaderboard: ✅ Yes`
- **Data shown**: Only what's in the student's analytics profile (no PII beyond name if consented)
- **Withdraw**: Student can opt out anytime; coach removes from next leaderboard update
