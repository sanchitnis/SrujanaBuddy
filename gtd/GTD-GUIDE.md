# GTD Lite Student Edition

This guide defines the minimal execution system used by SrujanaBuddy.

## Lists in scope
1. 00-inbox.md: unprocessed captures.
2. 01-next-actions.md: concrete next actions.
3. 02-projects.md: multi-step outcomes.
4. 03-runway-calendar.md: dated commitments.
5. 04-waiting-for.md: delegated or pending items.
6. 05-someday.md: parked ideas.
7. 07-weekly-review.md: review checklist and summary.

## GTD Lite rules
1. Every action starts with a verb.
2. Next Actions list should stay below 15 active items.
3. Projects list should stay below 8 active projects.
4. Weekly Review is mandatory once per week.
5. Every project must have exactly one visible next action.

## Processing flow
1. Capture to inbox quickly.
2. Clarify: actionable or not.
3. Organize into correct list.
4. Reflect in daily and weekly rhythm.
5. Execute based on context, time, and energy.

## Student-specific conventions
1. Prefix academic tasks with [ACA].
2. Prefix career tasks with [CAR].
3. Prefix wellbeing tasks with [WLB].
4. Include due dates only for real deadlines.
5. Add evidence links for completed milestones.

## Weekly review checklist
1. Empty inbox.
2. Update all project next actions.
3. Reconcile calendar and waiting-for.
4. Close stale or irrelevant items.
5. Set top 3 outcomes for next week.
