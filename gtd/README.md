# GTD Workspace (Student Edition)

This folder hosts the Markdown-native GTD Lite operating system for SrujanaBuddy students.

## Files
1. 00-inbox.md: fast capture.
2. 01-next-actions.md: executable tasks.
3. 02-projects.md: active outcomes.
4. 03-runway-calendar.md: schedule commitments.
5. 04-waiting-for.md: pending items.
6. 05-someday.md: deferred ideas.
7. 07-weekly-review.md: weekly control loop.
8. GTD-GUIDE.md: operating policy.
9. opportunity-radar.md: exploration backlog.

## Operating cadence
1. Daily: capture and execute.
2. Weekly: full review and reset.
3. Monthly: prune and reprioritize.

## Success criteria
1. Inbox at or near zero after weekly review.
2. Every project has one next action.
3. Calendar includes only hard commitments.
