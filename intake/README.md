# intake - Student Onboarding Layer

Primary audience: students, coaching operators, and implementers.

## Purpose

This folder contains onboarding assets for SrujanaBuddy.
Use it to capture baseline context and generate the first useful plan quickly.

## Contents

| File | Purpose |
|------|---------|

| apps/01-character-strengths.html | Character strengths baseline |

## Intake output expectations

1. Student context captured: stream, year group, aspiration map.
2. Current Srujana stage and readiness notes captured.
3. First-week starter plan generated.
4. At least one commitment captured for next 24 hours.

## App architecture rules

1. Single-file HTML only.
2. Inline CSS and JS only.
3. No network calls.
4. Offline-capable in browser.
5. Include copy-to-clipboard result export.
