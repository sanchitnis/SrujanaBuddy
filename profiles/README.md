# Profiles

This folder stores student profile templates and private student profile files.

## Public files in repository
1. _mentee-profile-template.md
2. README.md

## Private files (do not commit publicly)
1. [student-name]-profile.md
2. [student-name]-intake.md
3. Any periodic profile snapshots.

## Profile workflow
1. Copy the template to a student-specific file.
2. Complete intake baseline and current semester context.
3. Add diagnostics and evidence artifacts.
4. Update after each coaching session.
5. Review and recalibrate monthly.

## Naming convention
1. Template: _mentee-profile-template.md
2. Intake notes: [name]-intake.md
3. Live profile: [name]-profile.md
4. Snapshot: [name]-profile-YYYY-MM.md

## Privacy guidance
1. Student profile files contain sensitive data.
2. Keep profile files in private storage/repository.
3. Never commit personal profile files to public repos.
