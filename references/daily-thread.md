# Daily Thread
## 24-hour student operating rhythm

This file defines a practical daily rhythm for REVA student execution.

## Zone 1: Morning start (Antarmana + Sharira)
Duration: 30-60 minutes.

Checklist:
1. No-scroll start for first 20 minutes.
2. Breath or grounding practice for 5-10 minutes.
3. One-line day intention.
4. Quick body activation (walk/stretch).

## Zone 2: Deep learning block (Shiksha)
Duration: 90-180 minutes.

Rules:
1. Work on highest-cognitive task first.
2. Use retrieval and practice, not passive rereading only.
3. Keep phone away during focus block.

## Zone 3: Collaborative and execution block (Shiksha + Sangha)
Duration: 2-4 hours.

Use for:
1. Classes, labs, team tasks.
2. Instructor and peer coordination.
3. Assignment progress checkpoints.

## Zone 4: Regeneration block (Sharira)
Duration: 30-90 minutes.

Checklist:
1. Movement.
2. Nutrition and hydration check.
3. Short recovery break before evening work.

## Zone 5: Evening closure (Sangha + Antarmana)
Duration: 30-60 minutes.

Checklist:
1. Review commitments made and completed.
2. Log one learning reflection.
3. Plan one next action for tomorrow.
4. Set digital cutoff for sleep protection.

## Daily dopamine baseline (mandatory)
1. State: energy and mood (1-10).
2. Stimulation risk: what can derail focus today.
3. Natural reward anchor: one meaningful completion.
