# Dopamine Stewardship Protocol
## Student Attention and Motivation Stability

Dopamine stewardship is not moral judgment. It is attention hygiene.
Use this protocol in every daily planning session.

## Daily baseline check (mandatory)

1. State: energy and mood on a 1-10 scale.
2. Stimulation risk: what may hijack attention today.
3. Natural reward anchor: one meaningful completion to look forward to.

## Common risk patterns

1. Scroll loop before starting work.
2. Notification-driven context switching.
3. Urgency addiction without prioritization.
4. Late-night stimulation causing next-day cognitive debt.

## Counter-move library

1. 25-minute protected start block with phone away.
2. Notification batching windows.
3. One-task start rule before checking messages.
4. Sleep protection cutoff and next-day reset plan.

## Weekly dopamine audit

Track trend signals:
1. Attention quality across the week.
2. Follow-through on commitments.
3. Relapse triggers and recovery speed.

If repeated dysregulation persists for two weeks,
route one session to Inner Mastery focus-reset flow.

## Session close requirement

Close each daily session with:
1. One risk to watch.
2. One counter-move.
3. One completion anchor.
