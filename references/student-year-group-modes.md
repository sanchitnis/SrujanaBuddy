# Student Year-Group Coaching Modes
## Routing Defaults and Priority Templates

This file defines default coaching emphasis by year group.
Use it as a routing and prioritization baseline, then personalize.

## Year 1: Foundation Mode

Priorities:
1. Study system setup.
2. Campus integration and support network.
3. Daily discipline and GTD basics.
4. Sphere baseline and recovery hygiene.

Default weekly structure:
1. Daily focus planning.
2. Weekly sphere review.
3. Learning-to-learn session.

## Year 2-3: Development Mode

Priorities:
1. Skill depth and project rigor.
2. Internship and competition readiness.
3. Leadership through clubs and teams.
4. Stage 2-3 progression planning.

Default weekly structure:
1. Daily focus and runway checks.
2. Assessment/competition preparation block.
3. Portfolio evidence update.

## Final Year: Transition Mode

Priorities:
1. Placement readiness and interview prep.
2. Portfolio finalization.
3. Opportunity execution under deadlines.
4. Graduation transition planning.

Default weekly structure:
1. Daily focus with stress regulation.
2. Placement readiness session.
3. Mentor prep/debrief as needed.

## PG: Advanced Mode

Priorities:
1. Thesis and research cadence.
2. Publication and advanced project outputs.
3. Enterprise or applied research pathways.
4. Sustainable work rhythm and wellbeing.

Default weekly structure:
1. Deep work block planning.
2. Weekly research milestone review.
3. Monthly Panchakosha review.

## Routing override rules

1. Severe distress overrides year-group defaults and routes to support flow.
2. Red-zone runway risk routes to GTD rescue first.
3. Repeated dopamine dysregulation routes to focus-reset flow.
4. Mentor deadlines route to faculty coordination flow.
