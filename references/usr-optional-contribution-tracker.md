# USR Optional Contribution Tracker
## Student Contribution Paths Through University Social Responsibility

This file guides optional student contribution beyond academics through REVA's University Social Responsibility orientation.

## Why this exists

Not every student needs a large social-impact initiative.
Students do benefit from structured contribution that is:
1. Optional and capacity-aware.
2. Meaningful to community or campus.
3. Consistent with academic stability.
4. Aligned with REVA's USR and values-based development direction.

Reference source: `REVA University.md`, especially the sections on `Social Responsibility as a Core Mission` and the `Jagruti` initiatives.

## Contribution selection framework

Choose an optional contribution using these four lenses:

### Lens 1: USR Relevance
What real community, campus, or public-good need does this contribution support?

### Lens 2: Student Fit
What matches your strengths, schedule, values, and current stage of development?

### Lens 3: Evidence Potential
Will this contribution produce visible evidence such as event ownership, outreach, artifacts, reports, mentoring, awareness outcomes, or teamwork proof?

### Lens 4: Sustainability
Can you do this consistently without damaging academic runway, sleep, or health?

## Monthly health assessment

| Dimension | Question | Score (1-10) |
|-----------|----------|--------------|
| Clarity | Do I know what this contribution is trying to improve? | |
| Fit | Is this a realistic match for my current load and strengths? | |
| Consistency | Did I contribute regularly this month? | |
| Impact | Can I name one real output or benefit created? | |
| Collaboration | Am I building with others constructively? | |
| Sustainability | Is this contribution still healthy alongside academics and wellbeing? | |

## Suggested student contribution domains

| Domain | Example contribution |
|--------|----------------------|
| Campus mentoring | Support juniors with learning or adjustment |
| Sustainability | Awareness drive, waste reduction, climate action events |
| Electoral or civic awareness | Participation in university outreach efforts |
| Digital inclusion | Basic digital literacy or tool guidance |
| Community education | Volunteer tutoring or awareness support |
| Health and wellbeing awareness | Peer campaigns, student support events |
| Club/NSS/NCC service | Structured service and leadership participation |
| Public communication | Content, documentation, outreach, reporting |
