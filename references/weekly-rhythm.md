# Weekly Svadhyaya Rhythm
## Student weekly reset protocol

Use this weekly workflow to reset focus and maintain balance across five spheres.

## Weekly schedule baseline
1. Sunday: full review and next-week planning.
2. Monday: launch and runway check.
3. Tuesday-Thursday: deep work and execution blocks.
4. Friday: closure and carry-forward decisions.
5. Saturday: recovery and personal reset.

## Sunday review (mandatory)
Duration: 45-90 minutes.

Steps:
1. Score all five spheres (Shiksha, Antarmana, Sangha, Seva, Sharira).
2. Review completion log from the week.
3. Review runway board (D-21, D-14, D-3 risks).
4. Identify one recurring pattern.
5. Set one commitment per weak sphere.

## Weekly dopamine audit
1. What improved attention quality this week.
2. What repeatedly pulled attention away.
3. One environment change for next week.

## Weekly outputs
1. Top three priorities for the week.
2. One red-zone prevention action.
3. One support action (mentor/peer/family).
4. One evidence artifact action for portfolio.
