# STM — Sankalpa and Time Management Workspace

> *"A sankalpa is a commitment I make to start immediately and complete."*

This folder is the student's daily execution workspace for the STM system — ancient wisdom meets modern habit science.

## What is STM?

STM combines:
- **Sankalpa** (Vedic concept of sacred commitment) — more than a goal, it is a vow
- **Streaks** (Duolingo-style habit chains) — daily completion builds identity
- **Tiny wins** (Atomic Habits, James Clear) — smallest possible action that counts
- **Implementation intentions** (Gollwitzer) — "When X, I will Y for Z minutes"
- **Svadhyaya** (self-reflection) — weekly honest review without judgment

## Files in this workspace

| File | When to open | Takes |
|------|-------------|-------|
| `00-today-sankalpa.md` | Every morning | 5 min |
| `01-streak-tracker.md` | Daily (evening update) | 2 min |
| `02-weekly-sankalpa.md` | Monday setup, Friday review | 5 min |
| `03-someday-iccha.md` | When you have a wish to park | 1 min |
| `04-waiting.md` | When you need something from someone | 1 min |
| `05-sankalpa-archive.md` | After completing any sankalpa | 2 min |
| `06-weekly-svadhyaya.md` | Sunday evening | 15 min |

## Daily rhythm

```
Morning (5 min)  →  Open 00-today-sankalpa.md, set 1 big + 2 tiny
During day       →  Tatkala: any task < 2 min → do it NOW
Evening (3 min)  →  Check completion, update streak in 01-streak-tracker.md
                    Archive wins in 05-sankalpa-archive.md
Sunday (15 min)  →  06-weekly-svadhyaya.md — honest review + next week's plan
```
